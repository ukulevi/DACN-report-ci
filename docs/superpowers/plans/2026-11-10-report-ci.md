# Report CI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline.

**Goal:** Build a draft Vietnamese PDF from current Markdown/evidence at local and CI.
**Architecture:** Stdlib Python prepares a report/provenance, pinned portable
Pandoc/Tectonic render it, GitHub Actions stores private repository artifacts.
**Tech Stack:** Python3.11+, Pandoc3.13, Tectonic0.17.0, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-11-10-report-ci-design.md.

## Constraints and review focus

Preserve candidate/freeze/test decisions. Use only committed aggregate data.
No credentials/private arrays, no new training dependencies, no public publish.
Reject invalid metrics before PDF; verify tool download checksums; compile
Vietnamese correctly; expose build failures and source provenance; do not claim
remote CI success when account startup is blocked.
